
Seu Profissional

Plataforma web desenvolvida para conectar clientes a profissionais de diferentes áreas de serviços, permitindo cadastros simples e visualização de profissionais disponíveis de forma rápida e intuitiva.

---

## Preview

O sistema possui:

- Página inicial moderna;
- Cadastro de profissionais;
- Cadastro de clientes;
- Exibição dinâmica de profissionais cadastrados;
- Interface responsiva;
- Armazenamento utilizando `localStorage`.

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- LocalStorage

---

## Funcionalidades

### Cadastro de Profissionais

Os profissionais podem cadastrar:

- Nome completo;
- Serviço oferecido;
- Telefone;
- E-mail;
- Valor cobrado por hora.

---

### Cadastro de Clientes

Os clientes podem solicitar serviços informando:

- Nome completo;
- Serviço solicitado;
- Telefone;
- E-mail;
- Descrição do problema.

---

### Listagem Dinâmica

Os profissionais cadastrados são exibidos automaticamente na página:

profissionais.php

Os dados são armazenados localmente utilizando:

localStorage

---

## Como Executar o Projeto

### 1. Clone o repositório

git clone https://github.com/seu-usuario/seu-profissional.git

---

### 2. Abra em um servidor local

Você pode utilizar:

- XAMPP
- Laragon
- WampServer

---

### 3. Coloque o projeto na pasta do servidor

Exemplo utilizando XAMPP:

C:/xampp/htdocs/seu-profissional

---

### 4. Execute no navegador

http://localhost/seu-profissional
